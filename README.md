# Share-house Minecraft client download

[Download the desktop setup preview](https://github.com/owensantoso/sharehouse-minecraft-client/releases/tag/pilot-0.1.0-preview.1).

This small optional launcher pack selects **Minecraft Java26.3**, with an included setup guide. Windows and Mac use the same `.mrpack` file in [Prism Launcher](https://prismlauncher.org/download/). You can also use the ordinary official Java launcher and select26.3; no client mods are required for the current vanilla pilot. This preview is a starting point for a later selected modpack.

1. Install Prism, then **Add Instance → Import** the downloaded `.mrpack`.
2. Enable automatic Java detection/download in Prism's Java settings; this profile needs **Java25**. Sign into your own Microsoft account with a Minecraft Java licence.
3. Ask the host to allowlist your Java player name and send the current address. Launch the instance → Multiplayer → Add Server → join.

The archive contains version metadata and instructions only. Game/runtime downloads occur through the launcher. It contains no game/mod binaries, account files or preset server address. The current public server address is still being finalized; access details are shared by the host.

**Qualification:** archive structure, reproducibility, content allowlist, optional saved server format and five automated tests passed. Actual Prism import and gameplay through this package remain unverified. Please report the exact error and your platform if you help test it. Join, move, place/break a block, leave and rejoin to complete the representative check.

The pack is **desktop Java only**. iPhone/Android Java launchers are separate experiments. Stock mobile Minecraft is Bedrock Edition, a separate app-store purchase; its shared-world connection is being tested independently. No modded phone or Bedrock pack compatibility is claimed here.

Download the release's `README-SHAREHOUSE.md` for full steps and `SHA256SUMS` to verify files. Every player uses their own licensed account. The pack does not grant server allowlist or network access.
