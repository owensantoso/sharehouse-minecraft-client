# Share-house Minecraft client download

[Download the desktop setup preview](https://github.com/owensantoso/sharehouse-minecraft-client/releases/tag/pilot-0.1.0-preview.2).

This optional pack selects **Minecraft Java 26.3** and includes the **Share-house pilot** server entry. Windows and Mac use the same `.mrpack` file in [Prism Launcher](https://prismlauncher.org/download/). The ordinary official Java launcher can also join the same world without client mods.

1. Install Prism, then choose **Add Instance → Import** and select the downloaded pack.
2. Enable automatic Java detection/download in Prism's Java settings; this profile needs **Java 25**. Sign into your own Microsoft account with a Minecraft Java licence.
3. Ask Owen to allowlist your exact Java player name. Launch the instance → **Multiplayer → Share-house pilot → Join Server**.

For an existing official Java installation, choose **Multiplayer → Add Server** and enter **practically-documents.tun.ply.gg:60885**. The server must be running on JNOS and your account must be allowlisted.

The pack contains version metadata, setup instructions and a saved server entry. Game/runtime downloads occur through the launcher. It includes no game/mod binaries or account files. Proposed social mods are tracked separately and are not included in this vanilla pilot.

**Preview status:** archive integrity, deterministic bytes and strict saved-server decoding passed. Actual import and gameplay evidence for this release is described in its release notes. Each player's own-account launch and join still needs testing. Join, move, place/break a block, leave and rejoin; report the exact error and platform if something fails.

This pack is **desktop Java only**. iPhone/Android Java launchers remain separate experiments; it does not establish phone or mod compatibility.

For **Bedrock**, use your own licensed Bedrock app and Xbox/Microsoft account, ask Owen to allowlist your exact Bedrock gamertag, then add a server with address **grandmarigold.wdn.gg** and port **443**. This is a separate manual connection, not a Java-pack import. Desktop Bedrock 26.52 joined the shared world and rejoined after server/tunnel restart; iPhone/Android play and their add-server controls remain unverified. No Java licence is required for Bedrock access through the configured Floodgate bridge.

Download **README-SHAREHOUSE.md** for full steps and **SHA256SUMS** to verify the files. The public downloads need no GitHub login. Every player uses their own licensed account; the pack does not grant server allowlist access.
